# 🏥 Healthcare Stroke Risk Insights Dashboard | Power BI Project

## 📌 Project Introduction

The Healthcare Stroke Risk Insights Dashboard is a Power BI project designed to analyze patient healthcare data and identify important factors associated with stroke risk.

This dashboard transforms raw medical and patient data into interactive visual insights that help healthcare professionals, analysts, and researchers understand stroke patterns, patient demographics, health conditions, and risk indicators across different age groups and lifestyles.

---

# 🎯 Project Objective

The main goals of this project are:

* To analyze stroke-related healthcare data efficiently
* To monitor stroke patient statistics and risk percentages
* To identify high-risk patient groups
* To compare stroke patterns across age groups and gender
* To create an interactive healthcare analytics dashboard

# 📈 Dashboard Visualizations

## 5.1 Stroke Analysis by Gender

Displays the percentage distribution of stroke cases among male and female patients.

## 5.2 Smoking Status Analysis

Shows patient distribution based on smoking habits:

* Never Smoked
* Formerly Smoked
* Smokes
* Unknown

## 5.3 Stroke by Age Group and Gender

Analyzes stroke occurrence across different age categories and gender groups.

## 5.4 Average Glucose Level Analysis

Displays average glucose levels across age groups and stroke conditions.

## 5.5 BMI Analysis by Age

Shows BMI trends and variations across patient age groups.

## 5.6 Interactive Patient Filters

# 🔍 Key Insights

* Stroke risk increases significantly among older age groups.
* Patients with hypertension and heart disease show higher stroke probability.
* Smoking habits contribute to increased health risks.
* Average glucose levels vary notably across stroke and non-stroke patients.
* Gender-based analysis helps identify stroke occurrence patterns.
